## What I work on

- **Agent systems.** Tool-using LLM agents for enterprise data: retrieval, SQL generation, long-running conversation state, guardrails, and evaluation that catches regressions before users do.
- **Data and cloud pipelines.** Lakehouse and streaming pipelines on AWS, reconciliation services, and observability that makes failures visible.
- **Embedded to cloud.** Sensor firmware through to cloud ingestion and analytics, with delivery guarantees designed in from the start.

---

## Engineering principles

- Agents earn trust through validation and evaluation, not bigger prompts.
- State, context and tool access are design problems, not afterthoughts.
- Systems should fail visibly: retries, observability and delivery guarantees from day one.
- Infrastructure is code, so it can be rebuilt anywhere.
- Coding agents can write the change, but a second agent validates it before a human reviews.
